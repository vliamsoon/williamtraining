# VLIONIQ website

A static profile website for VLIONIQ and William Soon Wei Chee, featuring a navy-and-gold glass design, animated background, workshop information, customer feedback, and a Melaka location globe.

## Add to GitHub

Extract this ZIP and upload its contents to the root of your GitHub repository. Keep the `assets` folder alongside `index.html`. No build or dependency installation is required.

## Preview

Open `index.html` in your browser, or serve the repository folder with a local static web server.

## Files

- `index.html`: page content and contact links
- `style.css` and `sections.css`: layout and styling
- `app.js`: animated hero background
- `location.js`: animated location globe and WhatsApp icons
- `assets/`: portrait, workshop photo, and original feedback summary
- `favicon.svg`: website icon

## Hosting

Any static website host can serve this repository root. For GitHub Pages, choose Settings > Pages and publish from your main branch and root folder. For a static host that asks for a build command, leave it empty and use the repository root as the output directory.
